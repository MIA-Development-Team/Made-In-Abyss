# Red Whistle

The Red Whistle entry collects the first notes for the whistle system. It is a starting point for future articles about skills, combinations, and workbench recipes.

The node stores only stable article identifiers. The article body stays in its own Markdown resource, which lets a resource pack add or replace guide content without changing the client code.

## Planned branches

- Whistle progression and unlocks.
- Recipe and workbench references.
- Small embedded scenes that explain the interaction in context.
