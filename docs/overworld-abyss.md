# 主世界深渊

适用于 Minecraft 26.1.2 / NeoForge 26.1.2.109。

主世界以 `(X=0,Z=0)` 为中心生成干燥、贯通世界底部的深渊。默认对所有存档启用，仅影响新生成区块。已生成区块不会重建，因此测试新轮廓及群系请创建新世界。

## 地形轮廓

令 `R = 2 × abyssRadius`，默认320格。它控制山脊、外坡与连接范围；共享井壁另用基准 W=R+24，默认344格：

- `r <= R` 始终为空洞，世界底部不留基岩封底。
- 洞沿上表面约为 `Y=128`。`R < r < 2R` 不再雕刻从 `Y=0` 到 `Y=-64` 的倒置下表面，地下岩体继续延伸到世界底部；原有地下洞穴仍按密度和carver正常生成。`r <= R` 保持贯通。
- 从 `r=W` 的洞沿开始，地面先接近平坦，随后向外逐渐升陡。W～2R之间的前85%采用三次上升，最后15%以Hermite曲线连续收束到山脊，避免内外坡的尖折点。
- 山脊宏观目标为Y=256。每列在宏观表面高度采样当前世界已绑定种子的 `BlendedNoise`，以 `12 × tanh(noise)` 产生有界高度起伏，因此可以自然超过256。该噪声形成二维表面起伏，不在更高Y重新进入岩体，也没有水平256密度裁切。
- 越过山脊后通过一次高度混合下降，在最外缘恢复原体积密度并交还给原生成器。外坡宽度和曲线指数继续由既有配置控制。
- 主世界实际生成的基岩在 `r <= 2R`（含边界）替换为深板岩；范围外的基岩保持原样。洞口仍为空气，不添加封底。
Y=112以下的井壁与the_abyss最外壁共享同一 `SharedAbyssWall`。固定Xoroshiro随机算法、世界种子与 `mementoinabyss:shared_abyss_wall` 标识初始化参数为(.25,.25,160,160,8)的BlendedNoise；沿参考圆柱取噪声，并在共同4×4×4网格上插值噪声，径向距离始终逐方块计算。边界为 `W + 24 × tanh(3 × noise)`，默认320～368格。主世界在Y=112～144平滑收束回W并接到128肩部。

统一噪声高度使用the_abyss本地Y：主世界采样Y加上 `abyssMaxY - overworldMinY`，默认+448；the_abyss不偏移。实际维度边界从维度类型读取，沿用LOD和传送的坐标定义。井壁在原有插值、压缩和洞穴处理之后约束，避免两个维度不同的插值网格重新改变圆度。旧三字段 `OverworldAbyssCliff` Codec保持旧算法可读；新图用可选 `shared_wall`。最终洞口包装器的 `rough_wall` 保留最小R净空，旧图缺失该字段时仍沿用旧径向保护。

接缝两侧16格内使用相同处理尺度的共享密度，再用32格恢复当地洞穴；主世界只在井壁局部带生效，the_abyss最外圈顶部16格则连续封顶。岩顶内侧保持开口，封顶位于ENTRANCES、noodle、greatCaveNoodle之后。carver、含水层和表面规则依据相同约束保护岩顶和开口。最外壁两侧各8格的分支连续混合。General/Hopper/Noodle三种旧密度类型分别声明实际clamp范围[-5,6.25]、[-1.25,1.5625]、[-10,12.5]。

新密度组合在已识别的原版密度图中，替换 `sloped_cheese` 地形输入与顶部衰减节点，在原版处理结束后加入共享井壁与接缝约束。外坡的原地形参考高度取原 `sloped_cheese → blendDensity → interpolated` 未挖洞岩体包络在实际4×8插值网格上的最高正密度Y加1，按列缓存。洞穴及NOODLE的空隙可能在含水层阶段被岩石回填，因此不能用已挖洞最终密度的最高正值作为岩体高度，否则会把洞底突变带到山坡。该参考高度与 `宏观高度 + 12 × tanh(BlendedNoise)` 做一次高度混合，使主体外坡的地形输入沿Y单调。仅在最外围权重不超过0.02的窄带内，使用原平滑因子 `factor / 128` 归一化并恢复原始体积密度，在边界精确交还原生成器。局部顶部衰减移至默认 `Y=288～312`，保留抬高的山脊。原来的洞穴图、`blendDensity → interpolated → ×0.64 → squeeze` 和最终 `NOODLE` 约束继续参与生成，表面外皮保护另行控制。参考高度图参与序列化和子图遍历；批量密度评估先填充子图数组，保留原版 `CacheOnce` 的逐格语义，避免4×8×4单元内错误复用。

为避免世界高度上的洞穴入口噪声切断抬高的山体，`CaveGuard` 在表面下约8格内维持连续外皮，从8格到24格平滑交还原洞穴结果；外坡权重最后0.05的范围内，该保护也平滑退出。更深处保留原有洞穴，之后的真实carver阶段仍能切出洞穴和峡谷。旧的 `overworld_abyss_noise` 类型及旧字段继续可解码。历史字段 `sculpt_underside` 仅为旧密度图兼容而保留，解码后不再产生效果。

若其他模组提供的最终密度图不符合可确认的结构，使用单独完成处理的局部深渊分支，再与原最终密度混合；原图不被拆改或重复后处理。启动日志的 `Overworld abyss density path` 会说明使用了 `before_vanilla_interpolation` 还是 `independent_processed_branch`。

识别前先遍历并消除 `HolderHolder` 透明引用，让常量算术由原版工厂重新归一化。原版随包JSON会在嵌套节点外加入这些引用，直接按编程创建的节点结构匹配会漏掉 `interpolated → blendDensity`，使普通主世界错误进入备用分支。现在普通、巨型群系和放大化主世界的实际JSON都走已识别路径；真正未知的密度图继续保留原图，备用路径日志会列出各阶段计数，便于检查模组组合。

## 配置

配置位于 `worldGenSection`，退出并重新加载世界后生效；专用服务器需重启。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `overworldAbyssEnabled` | `true` | 是否生成主世界深渊 |
| `abyssRadius` | `160` | 既有深渊半径基准，64～10240；主世界使用其2倍 |
| `abyssOuterSlope` | `1.0` | 外坡曲线指数，0.5～3.0；小于1偏早下降，大于1偏晚下降 |
| `abyssSlopeBand` | `1.25` | 外坡宽度，以R为单位，1.0～2.0；宽度越大整体越缓 |

外边界为 `(2 + abyssSlopeBand)R`。默认井壁344±24格、最小净空320格、山脊640格、外边界1040格。LOD和下落传送的玩家生效半径为640格，独立于外坡宽度。关闭功能或修改参数不会改写已生成区块，新旧地形交界可能存在接缝。

## 接入与兼容

只在实际主世界维度的 `NoiseBasedChunkGenerator` 中组合该世界自己的 `RandomState`，不覆盖主世界维度/噪声设置JSON及其他模组的原始密度。群系源在运行时以包装器组合，保留原源和全部原有群系参数。超平坦及非噪声生成器跳过，其他维度不安装此改造。

内环（`r < 1.5R`，默认480格）固定为独立的 `mementoinabyss:overworld/the_abyss`，包含悬壁、128肩部和上升到约144的低坡。它复用原 `the_abyss/the_abyss` 的外观、音乐与装饰特征，并通过专用 `the_abyss/overworld/trees_skyfog` 复用现有skyfog树木和多层放置器（每层8次尝试），树木先于草和花生成，添加原版洞穴、地下洞穴与峡谷carver；原深渊维度群系的定义和carver列表保持不变。之后由原群系源选取群系，局部修正大陆性、侵蚀、奇异性和深度，温度与植被/湿度继续使用原噪声。原 `RandomState` 群系采样器同步重建，区块内部缓存采样器使用同一修改后的路由。若原源仍为明显隆起的坡地选择海洋/河流/海滩，则按温度选择主世界山地群系；原有陆地和地下群系继续保留。地形范围外的气候与群系选择完全交还原源。

carver选择与可见群系身份分开：主世界受影响区域的carver源区块通过保留的原群系源、修改前的气候采样器和生成器设置解析器取得carver列表，从而继续使用原版或其他模组提供的洞穴和峡谷配置。原气候采样器按RandomState以弱键保存，重复组合不会覆盖首次记录。重定向仅作用于 `applyCarvers` 的设置供应器，不改写群系定义、装饰特征或原深渊维度。

包装器的可选群系集合包含内环和陆地兜底群系，并重建装饰特征排序缓存，让内环植被等特征参与正常生成。保存的包装器可解码，重新载入时按当前配置与种子重新包装，关闭功能则恢复原源。

范围外直接返回原密度与原高度。含水层保留原始预估高度采样，其Deep Dark水位判断也仅使用原始侵蚀和深度输入，避免水体计算重复扫描新地表；实际群系仍读取修改后的气候。地表规则保留边界保护。范围内的地表预估按实际生成器的插值网格扫描组合后密度，并保留所属区块的Blender。网格角点与地表列使用有界的线程局部缓存；群系深度也读取同一地表结果，以处理山脊起伏和薄层地形。

洞内天然水、熔岩及结构地基密度不会封住贯通区域；后续结构、装饰、玩家放置的方块与流体不会被持续删除。修改同一生成阶段的模组仍需实测。危险的全局默认出生点会通过既有有界搜索避开深渊，个人床与重生锚记录不改动。

## 验证与运行

使用JDK25：

```powershell
.\gradlew.bat test
.\gradlew.bat jar
.\gradlew.bat runClient
```

测试覆盖128洞沿、圆滑山脊、地下岩体、含水层干燥、范围外不变、序列化与子图遍历，以及完整区块填充和地表构建。真实NoiseChunk回归按4格步长检查外坡交接，覆盖三种坡度参数、三个种子与四个方向；三维支撑连通检查覆盖256以上的岩体。完整地表阶段检查 `r <= 2R` 的实际基岩替换为深板岩、范围外基岩不变，以及 `r <= R` 的洞口贯通。还验证密度图识别、未知图兼容路径、负坐标插值、Blender传递，以及独立主世界群系定义与原定义的差异。实际carver回归分别运行原版洞穴、地下洞穴与峡谷算法，并确认其移除了真实石块；测试环境仅为缺失的可替换方块标签提供石头夹具，不用密度洞穴代替carver验证。

## 主世界显示深渊LOD

开启既有跨维度LOD开关后，主世界默认显示 `the_abyss` 维度的LOD。显示偏移按实际维度高度计算：`主世界minY - the_abyss的maxY`，其中maxY是最高方块上方的边界。默认偏移为-448，因此深渊最高方块Y=383显示在主世界Y=-65，其上边界Y=384与主世界最低建筑高度Y=-64衔接。

主世界连接使用独立标识 `mementoinabyss:the_abyss_in_overworld`，避免与大断层中的深渊LOD混用显示高度；切换连接会清空旧显示数据，同一深渊区块更新会同时通知两个观看维度。既有数据包显式声明的垂直连接仍优先。

隐式主世界连接仅在功能开启且玩家距原点的XZ水平距离 `<= 2R` 时生效。服务器每tick重新判定并停止范围外玩家的数据请求和发送；客户端同时停止渲染并释放网格。离开范围撤销该观看连接的懒生成请求；其他维度或其他符合条件的观看玩家仍可继续使用LOD。重新进入恢复请求，不能通过远处摄像机或客户端报文绕过服务器判定。

玩家在该范围内跌到 `Y < 主世界minY` 时传送到实际深渊维度，X/Z不变，`目标Y = 玩家Y - displayYOffset`，保留越界距离、速度及朝向。默认 `-65 → 383`。正好处于最低建筑高度不传送，超过2R则维持原版虚空掉落。此传送独立于LOD显示开关。

## 从深渊查看和返回主世界

`the_abyss` 同时显示下方既有大断层和上方主世界的LOD，两条连接各自保存数据流、网格、视图报告和缓存，不会在相同XZ区块坐标处互相覆盖。懒生成轮流调度不同连接，避免一侧长期占据生成名额。

向上连接使用 `mementoinabyss:overworld_in_the_abyss`，高度偏移为 `深渊maxY - 主世界minY`，默认+448；主世界Y=-64显示为深渊Y=384，主世界Y=256显示为深渊Y=704。客户端从同步维度类型注册表读取原版 `minecraft:overworld` 类型。

玩家在深渊中到达 `Y >= 深渊maxY` 时返回主世界，默认 `384 → -64`、`389.5 → -58.5`，保留X/Z、速度、朝向和越界距离。LOD和传送共用 `VerticalDimensionCoordinates` 的偏移与逆变换，不使用落点高度修正或水平比例缩放。反向LOD和返回传送不受距中心2R限制，也不依赖主世界深渊生成开关；LOD仍遵循既有总开关、视距和视锥筛选。显式上方连接优先，既有向下大断层连接保留。

## 26.1.2 草方块标签导致的森林缺失

本轮结合DeepSeek Harness独立审查与IDE游戏内有限次数诊断确认：主世界专用群系的森林条目、生成器的possibleBiomes和排序后的VEGETAL_DECORATION均正常，实际执行时却经常产生0个候选地面。26.1.2随包 `minecraft:dirt` 仅含dirt/coarse_dirt/rooted_dirt；grass_block/podzol/mycelium属于独立 `minecraft:grass_blocks`。原放置器只接受DIRT或深渊岩石，因此原深渊森林能在深渊材质上生成，而主世界草地基本无法种树。少量裸露泥土仍可能产生零星树木。

修复仅在TreeOnEveryLayerPlacement的有效地面判断中补充GRASS_BLOCKS，保留原DIRT、深渊岩石及无流体的树木可替换植被规则；不改变原深渊群系的特征定义，不依赖改动全局原版标签。原 `the_abyss/the_abyss` 本来没有森林特征，本次仍未向它添加森林；主世界 `overworld/the_abyss` 的专用森林特征保持启用。

旧Skyfog测试曾错误地把GRASS_BLOCK绑定进DIRT，掩盖了这个版本迁移错误。现改为从实际类路径资源合并读取DIRT及GRASS_BLOCKS的JSON，并明确断言grass_block不属于DIRT。修复前，草方块、灰化土、菌丝三层平台在花草覆盖下预期24个候选、实际0个，回归确实失败；修复后24个候选恢复，实际配置生成39个树干和451个树叶方块。

真实地形测试使用种子-1261428676705104120、主世界原版MultiNoiseBiomeSource、320布局半径、24..26×-1..1九个实际噪声与表面区块。群系查询经过带种子缩放的BiomeManager；实际ChunkGenerator.applyBiomeDecoration负责选择和排序特征，测试仅隔离无关结构及矿石，完整执行植被装饰。肩部产生13个候选，最终44个skyfog树干、568个树叶。群系注册、三种地面、真实地形装饰、carver与草地表面合计9项测试通过，Jar与diff检查通过。
