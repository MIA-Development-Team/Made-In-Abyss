# 主世界深渊

适用于 Minecraft 26.1.2 / NeoForge 26.1.2.109。

主世界以 `(X=0,Z=0)` 为中心生成干燥、贯穿世界底部的直壁深渊。默认对所有存档启用，仅影响新生成区块。已生成区块不会重建，因此测试新轮廓及群系请创建新世界。

## 地形轮廓

令 `R = ceil(1.5 × abyssRadius)`，默认240格；既有深渊维度仍使用原半径配置：

- `r <= R` 始终为空洞，世界底部不留基岩封底。
- 岩壁从世界底部近乎垂直延伸到 `Y≈128`，三维噪声在R外侧形成约十余格内的凹凸、凹陷和石岩凸出，不会缩小保证为空气的中央R范围。
- 从 `r=R` 的洞沿开始，地面先接近平坦，随后向外逐渐升陡。基本曲线为 `128 + (山脊高度 - 128) × ((r-R)/R)^3`，在 `r≈2R` 达到环山。
- 山脊基本高度随种子在224～256间起伏；三维细节会移动局部地表，新增内侧岩石不超过Y=256。
- 越过山脊后下降，混合原始地形密度，在外边界交还给原生成器。原有外围高山不受256上限约束。

宏观曲线与表面细节分别计算。`overworld_abyss_noise` 使用世界种子创建不可变的Minecraft `NormalNoise`，细节最大位移12格；径向岩壁与高度场取交集，最终目标密度使用 `clamp(value,-80,100)/16`。含水层与恶地柱、冰山防回填逻辑读取带噪声的洞形，因此不会削掉正密度的岩石凸出。

## 配置

配置位于 `worldGenSection`，退出并重新加载世界后生效；专用服务器需重启。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `overworldAbyssEnabled` | `true` | 是否生成主世界深渊 |
| `abyssRadius` | `160` | 既有深渊半径基准，64～10240；主世界使用其1.5倍（向上取整） |
| `abyssOuterSlope` | `1.0` | 外坡曲线指数，0.5～3.0；小于1偏早下降，大于1偏晚下降 |
| `abyssSlopeBand` | `1.25` | 外坡宽度，以R为单位，1.0～2.0；宽度越大整体越缓 |

外边界为 `(2 + abyssSlopeBand)R`。默认洞口240格、山脊480格、外边界780格。LOD和下落传送的玩家生效半径为720格，独立于外坡宽度。关闭功能或修改参数不会改写已生成区块，新旧地形交界可能存在接缝。

## 接入与兼容

只在实际主世界维度的 `NoiseBasedChunkGenerator` 中组合该世界自己的 `RandomState`，不覆盖主世界维度/噪声设置JSON及其他模组的原始密度。群系源在运行时以包装器组合，保留原源和全部原有群系参数。超平坦及非噪声生成器跳过，其他维度不安装此改造。

内环（`r < 1.5R`，默认360格）固定为 `mementoinabyss:the_abyss/the_abyss`，包含直壁、128肩部和上升到约144的低坡。之后由原群系源选取群系，局部修正大陆性、侵蚀、奇异性和深度，温度与植被/湿度继续使用原噪声。原 `RandomState` 群系采样器同步重建，区块内部缓存采样器使用同一修改后的路由。若原源仍为明显隆起的坡地选择海洋/河流/海滩，则按温度选择主世界山地群系；原有陆地和地下群系继续保留。地形范围外的气候与群系选择完全交还原源。

包装器的可选群系集合包含内环和陆地兜底群系，并重建装饰特征排序缓存，让内环植被等特征参与正常生成。保存的包装器可解码，重新载入时按当前配置与种子重新包装，关闭功能则恢复原源。

范围外直接返回原密度与原高度。含水层保留原始预估高度采样，地表规则也保留DeepSeek加入的边界保护。范围内的地表预估逐格扫描组合后密度，以处理噪声变化与其他模组的薄层地形。

洞内天然水、熔岩及结构地基密度不会封住贯通区域；后续结构、装饰、玩家放置的方块与流体不会被持续删除。修改同一生成阶段的模组仍需实测。危险的全局默认出生点会通过既有有界搜索避开深渊，个人床与重生锚记录不改动。

## 验证与运行

使用JDK25：

```powershell
.\gradlew.bat test
.\gradlew.bat jar
.\gradlew.bat runClient
```

测试覆盖直壁与128洞沿、三次曲线、种子与三维变化、噪声凸出保留、含水层干燥、上限与范围外不变、序列化与子图遍历，以及完整区块填充和地表构建。完整生成链使用多个种子与平原/恶地/冰海，并在外边界附近比较原始与改造后的方块。

仍需在新测试世界中人工检查最终视觉效果、首次出生与实际模组组合。这次测试不是游戏内截图验证。`overworld-abyss-gpt-review.md` 保留的是先前漏斗轮廓的历史交接记录，以本说明和当前实现为准。

## 主世界显示深渊LOD

开启既有跨维度LOD开关后，主世界默认显示 `the_abyss` 维度的LOD。显示偏移按实际维度高度计算：`主世界minY - the_abyss的maxY`，其中maxY是最高方块上方的边界。默认偏移为-448，因此深渊最高方块Y=383显示在主世界Y=-65，其上边界Y=384与主世界最低建筑高度Y=-64衔接。

主世界连接使用独立标识 `mementoinabyss:the_abyss_in_overworld`，避免与大断层中的深渊LOD混用显示高度；切换连接会清空旧显示数据，同一深渊区块更新会同时通知两个观看维度。既有数据包显式声明的垂直连接仍优先。

隐式主世界连接仅在功能开启且玩家距原点的XZ水平距离 `<= 3R` 时生效。服务器每tick重新判定并停止范围外玩家的数据请求和发送；客户端同时停止渲染并释放网格。离开范围撤销该观看连接的懒生成请求；其他维度或其他符合条件的观看玩家仍可继续使用LOD。重新进入恢复请求，不能通过远处摄像机或客户端报文绕过服务器判定。

玩家在该范围内跌到 `Y < 主世界minY` 时传送到实际深渊维度，X/Z不变，`目标Y = 玩家Y - displayYOffset`，保留越界距离、速度及朝向。默认 `-65 → 383`。正好处于最低建筑高度不传送，超过3R则维持原版虚空掉落。此传送独立于LOD显示开关。

## 从深渊查看和返回主世界

`the_abyss` 同时显示下方既有大断层和上方主世界的LOD，两条连接各自保存数据流、网格、视图报告和缓存，不会在相同XZ区块坐标处互相覆盖。懒生成轮流调度不同连接，避免一侧长期占据生成名额。

向上连接使用 `mementoinabyss:overworld_in_the_abyss`，高度偏移为 `深渊maxY - 主世界minY`，默认+448；主世界Y=-64显示为深渊Y=384，主世界Y=256显示为深渊Y=704。客户端从同步维度类型注册表读取原版 `minecraft:overworld` 类型。

玩家在深渊中到达 `Y >= 深渊maxY` 时返回主世界，默认 `384 → -64`、`389.5 → -58.5`，保留X/Z、速度、朝向和越界距离。LOD和传送共用 `VerticalDimensionCoordinates` 的偏移与逆变换，不使用落点高度修正或水平比例缩放。反向LOD和返回传送不受距中心3R限制，也不依赖主世界深渊生成开关；LOD仍遵循既有总开关、视距和视锥筛选。显式上方连接优先，既有向下大断层连接保留。

游戏内检查：开启LOD，在主世界中心洞口向下观察；跨越720水平半径并返回，确认网格消失/恢复且范围外不再请求；范围内跌破-64核对坐标和速度，范围外核对虚空行为；切换大断层并返回主世界检查旧高度网格；检查内环群系、不同种子的山脊群系，以及保存重载和关闭功能后的群系源恢复。
